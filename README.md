# DITBOX

**DITBOX 是面向影视制作设备的 macOS 资料管理与视频信号路由模拟工具。**它将设备参数、产品图片、选型对比和系统连接方案集中在一个客户端中，方便整理设备资料与推演制作车的信号链路。

## 主要功能

- **设备资料管理**：按类型、子类型、厂家和特性整理设备，记录价格、尺寸、重量、额定功耗、接口、图片、官网及手册链接；支持自定义参数和设备集合。
- **选型对比与统计**：对多台设备进行参数对比，统计所选设备的功耗、重量和价格，并按数量计算汇总结果。
- **视频信号路由模拟**：在可缩放的工作区中添加设备、连接端口、指定输出来源，检查信号路径与监视画面；支持保存工作区预设。
- **导入、导出与共享**：使用 `.dbi` 文件备份或传递完整数据库；设备列表和对比结果可导出为 PDF、Numbers 或 Excel 格式。
- **默认数据同步**：手动同步默认设备资料，同时保留本地设备及用户填写的内容。客户端也支持手动检查新版本。

DITBOX 仍在持续开发。路由模拟用于设备连接、方案推演以及教学演示，不代替实际设备兼容性、带宽或现场信号测试。
